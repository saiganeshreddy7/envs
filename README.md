# Environment Variables Manager (envs)

A simple VSCode extension for managing shell environment variables directly in the editor.

## Features

- Open shell config files with `envs` command
- Update environment variables
- Save/discard changes directly
- Supports zsh and bash

## Usage

1. Open Command Palette (Ctrl+Shift+P or Cmd+Shift+P)
2. Run `envs` to open shell config
3. Edit variables directly in the editor
4. Use save/discard commands as needed
